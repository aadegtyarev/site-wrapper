# Проверка Site Wrapper

Это тестовые сборки из GitHub Actions. Расширение desktop подписано Mozilla; Windows EXE и Android APK не имеют релизной подписи.

## Linux

Распакуйте архив целиком, оставив `site-wrapper` и `site-wrapper@aadegtyarev.github.io.xpi` рядом. В каталоге с файлами выполните:

```sh
chmod +x site-wrapper
./site-wrapper https://example.org
```

Нужен установленный Firefox. Для следующего запуска достаточно `./site-wrapper`.

## Windows

Распакуйте архив целиком, оставив `site-wrapper.exe` и XPI рядом. Запустите `site-wrapper.exe`; для проверки аргумента URL выполните в PowerShell из этого каталога:

```powershell
.\site-wrapper.exe https://example.org
```

Нужен установленный Firefox.

## Android

Установите APK для архитектуры устройства: `arm64-v8a` для большинства телефонов, `armeabi-v7a` для 32-битных устройств, `x86_64` для эмулятора. Если следующая отладочная сборка не устанавливается поверх предыдущей, удалите старую версию: CI подписывает debug APK новым ключом.

## Что проверить

На каждом устройстве задайте URL и пароль (от 12 символов), затем проверьте открытие сайта, оба режима, масштаб, смену языка, повторный запуск и вход в настройки. На desktop проверьте URL из аргумента: он должен действовать только до закрытия приложения. На Android откройте ссылку через системное меню «Открыть с помощью».

Сообщая об ошибке, укажите ОС и её версию, версию Firefox (для desktop), имя скачанного артефакта, шаги и результат. Пароль и ссылки с учётными данными не присылайте.
